My Projects

Spondylitis Detection Using Deep Learning (CNN)

Developed a deep learning-based system for detecting spondylitis using Convolutional Neural Networks (CNN). The system processes spinal X-ray images and classifies them to assist in detecting spondylitis. Image preprocessing, normalization and augmentation techniques were applied to improve the model performance. The CNN model was trained and evaluated using an 80:20 training and testing split and achieved approximately 97% accuracy.
